Cómo subir documentos
al repositorio

Guía paso a paso para entregar los insumos del Golden Dataset. No necesitas experiencia técnica para seguir este manual.

¿Para qué sirve este repositorio?

La plataforma de IA necesita aprender de los proyectos reales de ATISA para generar presupuestos precisos. Este repositorio es la carpeta compartida oficial donde cada área entrega sus documentos (precios unitarios, estudios de suelos, criterios BIM y un presupuesto validado de obra real). Una vez que los documentos estén aquí, el equipo técnico los convierte al formato que entiende el modelo de IA.

⏱ Fecha límite — Semana 1 de Mayo 2026

Todo el plan depende de recibir los 4 pilares esta semana. Cada día de retraso en la entrega recorre el calendario completo. Si tienes dudas sobre qué subir, revisa la sección de carpetas o contacta al equipo de desarrollo antes de la fecha.

Paso 1 de 4 — Preparar tu equipo (solo la primera vez)

1

Instalar GitHub Desktop

El programa que te permite subir archivos a GitHub sin usar comandos

1

Descarga GitHub Desktop

GitHub Desktop es un programa gratuito que hace todo el proceso visual, con botones y carpetas, sin necesidad de escribir comandos. Es el método más sencillo para colaborar en repositorios.

⬇ Descargar GitHub Desktop
💡

El sitio detecta automáticamente si tu equipo es Windows o Mac y te ofrece la versión correcta.

2

Instala el programa

Abre el archivo que descargaste (GitHubDesktopSetup.exe en Windows o GitHubDesktop.zip en Mac) y sigue las instrucciones. La instalación es igual que cualquier otro programa.

GitHub Desktop — Instalador
🖥️
Instalando GitHub Desktop...
Esto tarda menos de un minuto.
3

Inicia sesión con tu cuenta de GitHub

Al abrir GitHub Desktop por primera vez te pedirá que inicies sesión. Haz clic en Sign in to GitHub.com e ingresa el correo y contraseña de tu cuenta de GitHub.

⚠️

Si no tienes cuenta de GitHub, crea una gratuita en github.com con tu correo de ATISA. Luego notifica al equipo de desarrollo tu nombre de usuario para que te den acceso al repositorio.

Paso 2 de 4 — Descargar el repositorio a tu equipo

2

Clonar el repositorio

"Clonar" = descargar una copia local del repositorio en tu computadora

1

Abre GitHub Desktop y haz clic en "Clone a repository"

En la pantalla de inicio de GitHub Desktop verás la opción Clone a repository from the Internet. Haz clic ahí.

GitHub Desktop
Let's get started!
⬇ Clone a repository from the Internet
Descarga un repositorio que ya existe en GitHub
➕ Create a new repository
📂 Add an existing repository
2

Busca el repositorio "atisa-golden-dataset"

En la pestaña GitHub.com del panel de clonación, escribe en el buscador:

atisa-golden-dataset

Selecciónalo de la lista y haz clic en Clone.

💡

¿No aparece el repositorio? Significa que el equipo de desarrollo todavía no te ha dado acceso. Envíales tu nombre de usuario de GitHub para que te agreguen como colaborador.

3

Elige dónde guardar la carpeta en tu equipo

GitHub Desktop te preguntará en qué carpeta de tu computadora quieres guardar el repositorio. Puedes dejarlo en la ubicación que sugiere (Documentos/GitHub/atisa-golden-dataset) o elegir otra. Haz clic en Clone para confirmar.

✅

Cuando termine de clonar, verás una carpeta llamada atisa-golden-dataset en tu equipo con las 4 subcarpetas del proyecto adentro.

Paso 3 de 4 — Copiar tus documentos a la carpeta correcta

3

Agregar tus documentos

Copia tus archivos a la subcarpeta que corresponde a tu área

1

¿En qué carpeta va mi documento?

Dentro de la carpeta atisa-golden-dataset encontrarás estas 4 subcarpetas:

📁
financiero/
Catálogo de precios unitarios históricos · Excel, PDF, CSV
📁
tecnico/
Estudios de mecánica de suelos y reportes de volúmenes · PDF, Excel
📁
bim/
Criterios de diseño y nomenclatura de familias Revit · PDF, Excel
📁
ground_truth/
Presupuesto final validado de obra real · Excel, PDF
2

Nombra tus archivos con este formato

Para que el sistema los procese automáticamente, usa este formato al nombrar cada archivo antes de copiarlo:

{carpeta}_{descripcion-corta}_{AÑO-MES}.{extension}
Ejemplo correcto Carpeta destino
financiero_precios-unitarios_2025-01.xlsx financiero/
tecnico_ems-monterrey_2024-06.pdf tecnico/
bim_criterios-diseno-nave_2025-03.pdf bim/
ground_truth_presupuesto-50000m2_2024-11.xlsx ground_truth/
⚠️

No uses espacios, acentos ni caracteres especiales (ñ, /, &) en el nombre del archivo. Usa únicamente letras, números y guiones.

3

Copia el archivo a la carpeta correspondiente

Abre el Explorador de archivos (Windows) o el Finder (Mac), navega hasta la carpeta atisa-golden-dataset y arrastra tus archivos a la subcarpeta correcta, exactamente igual que copias cualquier archivo en tu computadora.

✅

Una vez que copies el archivo, GitHub Desktop lo detectará automáticamente y lo mostrará en su pantalla principal como un cambio pendiente de subir.

Paso 4 de 4 — Guardar y subir los cambios

4

Hacer el Commit y el Push

"Commit" = guardar los cambios · "Push" = subirlos al repositorio compartido

1

Abre GitHub Desktop

Verás en el panel izquierdo todos los archivos que acabas de copiar, marcados con un ícono verde + (archivos nuevos). Si modificaste uno existente, aparecerá con un punto amarillo.

2

Escribe un mensaje que describa lo que subes

En la parte inferior izquierda del programa hay un campo llamado Summary. Escribe una frase corta que explique qué estás subiendo. Esto queda registrado para que todos sepan quién subió qué y cuándo.

ÁreaEjemplo de mensaje
PresupuestosAgrego catálogo de precios unitarios 2025
Ingeniería CivilSubo 3 estudios de mecánica de suelos
BIMAgrego manual de criterios de diseño nave tipo

3

Haz clic en "Commit to main"

Este botón guarda los cambios en tu copia local del repositorio. Piénsalo como hacer clic en "Guardar" en Word, pero con un registro histórico que nunca se borra.

4

Haz clic en "Push origin" para subir al servidor

Después del commit, aparecerá un botón azul en la parte superior que dice Push origin con un número que indica cuántos cambios están pendientes de subir. Haz clic en ese botón para que los documentos queden disponibles para todo el equipo.

¡Listo! Tus documentos ya están en el repositorio y el equipo de desarrollo puede verlos y procesarlos.

Checklist antes de terminar

Antes de dar por entregado tu pilar, revisa que hayas completado lo siguiente:

  • Instalé GitHub Desktop e inicié sesión con mi cuenta
  • Cloné el repositorio atisa-golden-dataset en mi equipo
  • Nombré mis archivos siguiendo el formato: pilar_descripcion_AAAA-MM.ext
  • Copié mis archivos a la subcarpeta correcta (financiero / tecnico / bim / ground_truth)
  • Escribí un mensaje descriptivo en el campo Summary antes del commit
  • Hice clic en Commit to main
  • Hice clic en Push origin para subir al servidor
  • Verifiqué en github.com que mis archivos aparecen en el repositorio

Preguntas frecuentes

❓ No encuentro el repositorio al buscar en GitHub Desktop

Significa que el equipo de desarrollo todavía no te ha dado acceso. Envía tu nombre de usuario de GitHub al equipo de desarrollo y te agregarán como colaborador. Una vez que te confirmen el acceso, vuelve a buscar el repositorio.

❓ Subí un archivo incorrecto o con el nombre equivocado, ¿qué hago?

No hay problema. Simplemente borra el archivo de la carpeta en tu computadora, renómbralo correctamente, vuelve a copiarlo a la carpeta y haz un nuevo commit + push. El historial de GitHub guarda todos los cambios, nunca se pierde nada.

❓ GitHub Desktop me pide hacer "Fetch" o "Pull" antes de subir, ¿qué hago?

Eso significa que alguien más subió archivos mientras tú trabajabas. Haz clic en el botón Fetch origin primero (descarga los cambios del servidor), y luego aparecerá el botón Push origin para que puedas subir los tuyos. Nunca se perderán tus archivos en este proceso.

❓ ¿Puedo subir varios archivos al mismo tiempo?

Sí. Copia todos los archivos a sus respectivas carpetas y GitHub Desktop los mostrará todos en la lista de cambios. Escribe un mensaje general que los describa a todos ("Entrego pilares financiero y técnico completos") y haz un solo commit + push para todos juntos.

❓ ¿Puedo subir archivos directamente desde el navegador sin instalar nada?

Sí, pero solo si vas a subir archivos sueltos. Entra a github.com/LDominguezIA/atisa-golden-dataset, navega a la carpeta correcta, y haz clic en el botón Add file → Upload files. Arrastra tus archivos y haz clic en Commit changes al final de la página.

❓ ¿El repositorio es seguro? ¿Quién puede ver mis documentos?

El repositorio es privado. Solo las personas que el equipo de desarrollo ha invitado explícitamente pueden ver o descargar los documentos. Nadie fuera del proyecto tiene acceso.
