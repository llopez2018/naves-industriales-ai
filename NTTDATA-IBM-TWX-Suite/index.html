Scripts de configuración
Instalación y verificación
🪟
Instalador Windows
Script PowerShell que instala todo automáticamente: clona el repo, organiza carpetas y registra el comando global.
instalar_windows.ps1
🍎 🐧
Instalador macOS / Linux
Script bash equivalente para Mac y Linux. Detecta la carpeta Documentos y copia todo con permisos correctos.
instalar_mac_linux.sh
✅
Verificador de instalación
Script Python que comprueba todos los módulos, el comando CLI, herramientas externas y hace un test funcional con un TWX sintético.
verificar.py
